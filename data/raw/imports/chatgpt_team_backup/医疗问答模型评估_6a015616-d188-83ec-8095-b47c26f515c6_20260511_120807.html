# 五、建议的训练路线（很重要）

你现在最危险的坑：

# 直接 SFT judge 输出

这会导致：

- verbosity bias
- position bias
- score collapse
- generative judge hallucination

---

# 更推荐：

## Stage 1 — Critique SFT

训练：

{
  "question": "...",
  "response": "...",
  "evaluation": {
    "safety": "...",
    "accuracy": "...",
    "missing_info": "...",
    "final_score": 3
  }
}


重点学：

- critique pattern
- rubric grounding

---

## Stage 2 — Pairwise preference

训练：

- 哪个回答更好
- 哪个更安全
- 哪个遗漏更严重

这个提升会巨大。

因为 judge 的核心其实是 ranking。

---

## Stage 3 — Calibration tuning

专门加入：

- borderline cases
- uncertainty
- partially correct
- harmful reassurance
- under-triage
- overconfidence

医疗 judge 最大难点在这里。

---

# 六、一个非常关键的建议

你应该：

# 让 checker 输出“证据化 critique”

而不是直接分数。

例如：

{
  "factuality": {
    "score": 2,
    "evidence": [
      "The response incorrectly states ..."
    ]
  }
}


原因：

---

## 纯 scalar score 非常不稳定

医疗场景尤其如此。

而：

# rationale-grounded judge

会：

- 稳定很多
- 更可解释
- 更容易蒸馏
- 更容易后续 reward modeling

从下往上扫描：

```python
for col in columns:
    write_ptr = bottom
    for row from bottom → top:
        if not empty:
            move to write_ptr
            write_ptr--
```

---

### 3. 填充算法（Spawn）

```python
while write_ptr >= 0:
    board[write_ptr][col] = spawn_queue.pop()
```

### 4. 连锁机制（Cascade Loop）

```python
while True:
    matches = find_matches()
    if not matches:
        break
    eliminate(matches)
    apply_gravity()
    spawn_new()
```

# 一、为什么你会频繁连锁（本质原因）

### 1. 状态空间太“稠密”

- 4种动物 → 每格随机命中概率 = 1/4
- 连续3个概率 ≈ 1/16（横/纵叠加更高）

再叠加：
- 掉落会“压缩相同元素”
- 补充是随机的

👉 结果：
> 每次消除后，棋盘会进入一个**更容易再次匹配的状态**

---

### 2. 重力是“匹配放大器”

重力本质做了两件事：

```text
1. 把相同元素压在一起（增加局部密度）
2. 破坏原有结构（引入新组合）
```

👉 这会显著提高 match probability

---

### 3. 候选池（supply）是纯随机

这点是最大问题：

> 你在“持续往棋盘注入可形成match的随机变量”

# 1. 最新一代：Medical Reasoning SFT（最值得关注）

## urlOctoMed/Medical-Reasoning-SFT-Megahttps://huggingface.co/datasets/OctoMed/Medical-Reasoning-SFT-Mega

- 2025 年的数据
- 173 万条
- 带 reasoning trace（CoT）
- 医学推理风格非常接近 DeepSeek-R1/o1 路线
- 结构很适合：
- Qwen3.x
- Llama 3.x
- DeepSeek distilled 系列
- medical reasoning agent

核心字段：

{
  "system_prompt": "...",
  "question": "...",
  "answer": "...",
  "responses": "<think>...</think> final answer"
}


特点：

- 明确区分：
- reasoning
- final answer
- 非常适合：
- SFT + GRPO
- reasoning distillation
- test-time scaling
- verifier training

规模和质量目前都属于第一梯队。 citeturn0search1

# 2. HuatuoGPT-o1 系路线（现在国内很多人在用）

## urlFreedomIntelligence/medical-o1-reasoning-SFThttps://huggingface.co/datasets/FreedomIntelligence/medical-o1-reasoning-SFT

这个现在非常火。

特点：

- 2025 年更新
- 专门给 HuatuoGPT-o1 做的
- verifier-based filtering
- GPT-4o 生成
- 医学可验证问题（verifiable medical problems）

重点是：

它不是普通 instruction dataset。

它本质是：

> 医疗版 o1 reasoning corpus

很适合：

- reasoning SFT
- DeepSeek-R1 风格蒸馏
- long-CoT 医疗模型

而且很多 Qwen 医疗微调现在直接拿它做基础。 citeturn0search6turn0search7

# 3. Microsoft 的 MediFlow / MediPhi（非常强）

## urlmicrosoft/MediPhi-Instructhttps://huggingface.co/microsoft/MediPhi-Instruct

微软 2025 ACL 的东西。

里面提到：

- MediFlow
- 250 万 instruction 数据
- 14 类 clinical NLP tasks
- 98 种 document types
- JSON structured output support

这类数据和传统 QA 最大区别：

它不是“医学问答”。

它是：

> 临床 NLP instruction alignment

包括：

- ICD coding
- radiology
- entity extraction
- summarization
- structured output
- clinical IE

如果你们以后要做：

- EMR agent
- 病历结构化
- 医疗知识图谱
- 医疗信息抽取

这一类数据价值非常高。 citeturn0search2

# 5. 老一代但仍有用的数据

## urllavita medical instruction tuning collectionhttps://huggingface.co/collections/lavita/medical-instruction-tuning-datasets

里面包括：

- MedInstruct
- ChatDoctor
- Alpaca-Med
- PMC-LLaMA instructions

这些现在的问题：

### 优点

- instruction 格式标准
- 便于快速起步
- 小模型容易收敛

### 缺点

- reasoning 很弱
- hallucination 较重
- 医学严谨性不足
- 很多是 GPT-3.5 时代 synthetic

现在更适合：

- warmup SFT
- alignment initialization
- multi-stage curriculum

不太适合直接当最终 SFT 主体。 citeturn0search0

# 目前一个明显趋势

2026 已经越来越不流行：

question -> answer


而更流行：

question
-> reasoning trace
-> verification
-> structured output
-> grounded evidence


也就是：

- CoT
- verifier
- grounded reasoning
- agentic clinical workflow

这是现在 medical SFT 的主方向。

# 一、先理解 SBRAD 是什么

SBRAD = sinus bradycardia（窦性心动过缓）

临床定义核心：

- 心律是窦性
- 但心率低（通常 < 60 bpm）

因此：

> “慢” 是这个疾病最核心的判别特征。

不像 1AVB 看 PR interval，CLBBB 看 QRS morphology。

---

# 二、他们做了什么

核心操作：

> 把所有 SBRAD ECG 的心率统一“拉伸/压缩”到 75 bpm。

原文：

> each heartbeat was time-warped to a target rate of 75 bpm

也就是：

- 原本 45 bpm → 加快
- 原本 50 bpm → 加快
- 原本 55 bpm → 加快

最终：

- 所有 beat 的节律看起来都像 75 bpm

但：

- QRS 形状保留
- 波形振幅保留
- morphology 尽量不变

只改变：

# “慢速节律”这个信息

---

# 三、time-warping 怎么理解

这不是简单删点。

而是：

# 时间轴缩放

比如：

原 ECG：

```text
|----beat1----|--------beat2--------|
```

RR interval 很长（心跳慢）

time-warp 后：

```text
|--beat1--|--beat2--|
```

RR interval 变短（心跳变快）

但每个 beat 内部：

- QRS 形状
- P wave
- T wave

尽量保持。

---

# 四、为什么说这是 “global perturbation”

因为：

# 心率是全局属性

心率来自：

\[
HR = \frac{60}{RR}
\]

它依赖：

- beat 与 beat 的间隔
- 整段信号的时间结构

不是某个局部窗口。

所以：

- PR interval masking → 局部 perturbation
- QRS masking → 局部 perturbation
- rate normalization → 全局 perturbation

作者因此特别强调：

> not window-based

因为它不是遮挡一小段。

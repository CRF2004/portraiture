#### 方法1：hook Claude Code 请求

  - system prompt
  - messages
  - tool schemas

- 给每个 MCP server 加 wrapper
- 统计其 schema + 返回内容 token

### 输出指标（用于 fork 判断）

```python

    <0.6 → safe

    >0.8 → critical
```

## 它具体是干什么的？

这类工具通常会做几件事（和你理解的完全一致）：

1. **文本建模**
   - 输入：title / abstract / full draft  
   - 用 **BERT / SciBERT / embedding** 建模论文语义

2. **期刊/会议画像**
   - 用历史论文（scope、topics、keywords）
   - 学习每个期刊的“语义分布”

3. **相似度 + 规则筛选**
   - Topic match（主题相似度）
   - Method match（ML / DL / statistics）
   - 应用领域（clinical / bioinformatics / imaging）
   - 有时还会考虑 *impact / acceptance pattern*

4. **输出**
   - Top-K 期刊或会议
   - 匹配理由（关键词重合、主题相似）
   - 有的还会给 *risk*（偏保守 or 偏冲高分）

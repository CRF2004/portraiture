但我觉得有必要再说清楚一点，因为这是你整篇文章方法学成立的关键之一。审稿人很可能会问：

“为什么这些 control 是合理的？为什么不是别的区域？random window 算不算太弱？QRS control 对 1AVB 会不会太强？SBRAD 的 global target 和 local controls 是否公平？”

你现在有回应这些问题的材料，但分散在 Methods、Table I、Table II、1AVB sensitivity、Discussion 里。建议加一个很短的小段，放在 III-C Disease-Centered Audit Panel 或 III-D Perturbation Design 开头/结尾，专门叫：

Control-region selection rationale

可以写成这样：

> Matched controls were selected to satisfy three criteria. First, they had to be anatomically proximate to the target pathway so that the comparison was not trivially easy. Second, they had to represent a physiologically distinct signal component, making them plausible alternative information channels rather than irrelevant background. Third, they had to be perturbable under the same operator and windowing protocol whenever possible, so that target-control differences reflected pathway specificity rather than intervention differences. For example, the 1AVB PR-target window was compared with an adjacent non-overlapping QRS control because QRS morphology is a plausible shortcut for automated 1AVB labels, whereas ST and random non-PR windows provide weaker anatomical controls. For BBB, ST and random non-QRS windows test whether QRS morphology dominates nearby non-QRS signal. For AFIB, shifted pre-QRS and ST controls test whether atrial-window effects exceed neighboring non-atrial intervals. For SBRAD, because rate is a global property, local QRS/ST/random controls were used as morphology-based alternatives rather than identical local-window controls.

这个段落的价值很大：

1. 防止审稿人觉得 control 是 post hoc 选的。
你文章强调 “predefine / preregistered / disease-centered”，那 control 选择也要显得是规则化的，而不是看到结果后挑的。

2. 解释 1AVB 的 QRS control 为什么合理。
这点尤其重要。你的 1AVB 结论是“PR sensitivity exists but not PR specificity”，但如果读者觉得 QRS control 过强或不公平，就会攻击 ASS 结论。你要主动说：QRS 正是 plausible shortcut，所以它是必要的 strong matched control。

3. 解释 SBRAD 的 hybrid control。
SBRAD 的 target 是 global rate normalization，而 controls 是 local QRS/ST/random。这个最容易被质疑“不同类 perturbation 不可比”。你需要明确：这不是为了做完全同形扰动，而是为了测试“rate information 是否超过 morphology alternatives”。

4. 让 Table I / II 更有方法学支撑。
现在 Table I、II 列得很清楚，但缺少一段“选择原则”。加这一段之后，表格就不是清单，而是规则的实例化。

一段 150–220 words 足够。你现在论文已经很长了，不要再扩一大节。最合适的位置是 III-C Clinical anchoring 后面，因为那里已经在说 target/control grounded in ECG diagnostic criteria。加完后，Discussion 里可以不用再展开，只在 limitations 里承认：control choices remain clinically motivated design choices, not unique ground truth.

在 Claude Code 里停止 /goal，直接输入：

/goal clear


也可以用这些别名：

/goal stop
/goal cancel
/goal off
/goal reset
/goal none


如果它正在非交互模式里一直跑，比如 claude -p "/goal ..."，用：

Ctrl + C


另外，开新会话 /clear 也会移除当前 active goal。官方文档也写了：/goal clear 用于提前清除目标，stop/off/reset/none/cancel 都是别名。citeturn950293search0turn950293search1

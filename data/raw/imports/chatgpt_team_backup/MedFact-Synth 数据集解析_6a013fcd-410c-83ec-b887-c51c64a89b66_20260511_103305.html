这个数据集本质上是一个 “医学事实验证（medical fact-checking）+ rationale generation” 数据集。
它不是传统的 instruction-following QA，而是：

> 给定一个医学 claim（断言） + 一篇 article（证据文献）
> 模型需要判断：
> - 支持 / 反对 / 中立 的程度
> - 并生成推理解释（rationale）

数据集主页已经把字段定义得比较清楚了。citeturn0search0

---

# 一、先理解它到底是什么任务

它的数据结构：

claim + source(article)
    ↓
生成：
    synthetic_label (-2~2)
    assistant_prompt（推理+结论）


本质上类似：

输入：
Claim: XXX
Article: YYY

输出：
This article partially supports the claim because...
Label: +1


---

# 二、字段怎么理解（核心）

下面是最关键的字段：

| 字段 | 含义 | 微调是否保留 |
|---|---|---|
| claim | 待验证断言 | ✅ |
| source | 证据文献 | ✅ |
| synthetic_label | 标签（-2~2） | ✅ |
| assistant_prompt | 模型推理结果 | ✅ |
| user_prompt | 已经构造好的用户输入 | 可选 |
| system_prompt | system instruction | 可选 |
| claim_potential | support/refute（生成时的意图） | ❌通常不用 |
| pmid | PubMed ID | ❌通常不用 |

---

# 三、synthetic_label 怎么理解

这是 5 分类：

| label | 含义 |
|---|---|
| -2 | Strong Contradiction |
| -1 | Partial Contradiction |
| 0 | Neutral |
| +1 | Partial Support |
| +2 | Strong Support |

这意味着：

这个数据集既可以做：

---

## 1. 分类任务（推荐）

输入：

Claim + Article


输出：

2


或者：

Strong Support


---

## 2. CoT/Rationale 微调（更推荐）

输入：

Claim + Article


输出：

The article directly supports...
Therefore the label is +2.


这其实就是 assistant_prompt 的用途。

---

# 四、assistant_prompt 是什么

这是最容易误解的地方。

它其实已经是：

> 一个完整的 reasoning answer

里面包含：

- 思维链（think）
- rationale
- 最终标签

例如：

<think>
The article discusses...
...
</think>

The article strongly supports the claim.
Label: 2


因此：

# 这个数据集天然适合：

- SFT
- CoT SFT
- reasoning distillation
- verifier training
- reward modeling

---

这取决于你要训练什么。

# 方案1（最推荐）：Instruction SFT

# 方案2：纯分类微调

如果你想训练 verifier：

  "label": 2
}

- BERT
- BioBERT
- PubMedBERT
- DeBERTa

# 方案3：Chain-of-Thought 微调（非常适合）

你可以保留 <think>：

    },
    {
      "role": "assistant",
      "content": "<think>...</think>\n\nLabel: +1"
    }
  ]
}


这很适合：

- reasoning SFT
- medical rationale generation
- verifier reasoning

# 六、实际推荐的数据整理方式（非常重要）

# 七、如何从 assistant_prompt 提取 rationale

assistant_prompt 里面通常：

...
</think>


你可以：

## 去掉 think，只保留最终解释

# 十、一个完整转换脚本（推荐）

from datasets import load_dataset
import json

label_map = {
    -2: "Strong Contradiction",
    -1: "Partial Contradiction",
     0: "Neutral",
     1: "Partial Support",
     2: "Strong Support"
}

ds = load_dataset("ncbi/MedFact-Synth", split="train")

output = []

for x in ds:

    user = f"""Claim:
{x['claim']}

Article:
{x['source']}"""

    assistant = f"""{x['assistant_prompt']}

Verdict: {label_map[int(x['synthetic_label'])]}"""

    output.append({
        "messages": [
            {
                "role": "system",
                "content": "You are a biomedical evidence verification expert."
            },
            {
                "role": "user",
                "content": user
            },
            {
                "role": "assistant",
                "content": assistant
            }
        ]
    })

with open("medfact_sft.jsonl", "w") as f:
    for item in output:
        f.write(json.dumps(item) + "\n")

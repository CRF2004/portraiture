## ✅ 2️⃣ 核心控制循环（必须固定下来）

for i in range(max_iter):

    plan = planner(state)

    result = executor(plan)

    critique = critic(result, spec)

    verified = verifier(result)

    if critique.pass and verified.pass:
        break

    state = update(state)


👉 这就是你要的“loop everything”，但注意：

- ❗loop 是 受控的
- ❗不是 agent 自己随便 loop

# 🔥 一个可落地的“通用 skill”设计（给你直接用）

我给你一个可以直接塞进 Claude Code 的版本：

---

## 🧩 Skill: loop_everything

You are an orchestrator agent that MUST solve the user's task through iterative refinement.

## Phase 1: Specification
- Rewrite the user's request into:
  - goal
  - constraints
  - acceptance criteria
- Ask clarification questions if needed

## Phase 2: Iterative Loop (max 6 iterations)

For each iteration:

1. PLAN
- Decide the next best action

2. EXECUTE
- Perform the action

3. CRITIQUE
- Evaluate:
  - Is the goal satisfied?
  - What is missing?
  - What is incorrect?

4. VERIFY (if possible)
- Use objective checks:
  - tests
  - structure
  - consistency

5. DECIDE
- If all acceptance criteria met → STOP
- Else → refine and continue

## Rules:
- Do NOT loop blindly
- Stop early if solved
- Reset approach if stuck for 2 iterations

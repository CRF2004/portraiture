# 一、最可能考的核心重点

## 第一档：很可能考，必须会

### 1. 过拟合、欠拟合、模型选择

这几乎一定会考选择、填空、简答或综合题。

你要会说：

**欠拟合**：模型太简单，训练误差和测试误差都高。  
解决：增大模型、增加特征、训练更久、降低正则化。

**过拟合**：训练误差低，测试误差高。  
解决：增加数据、数据增强、权重衰退、Dropout、早停、简化模型。

**模型选择**：训练集训练，验证集调参，测试集最后评估。

高频简答题：

> 为什么不能用测试集调参？

答：因为测试集用于最终评估泛化能力，如果用测试集调参，会导致测试结果被“泄露”，评估不真实。

---

### 2. 线性回归、Softmax 回归、MLP

这是深度学习基础部分，选择、填空、代码都很容易考。

你要掌握：

**线性回归**  
用于回归问题，输出连续值。  
损失函数常用平方损失：

\[
l=\frac{1}{2}(y-\hat y)^2
\]

**Softmax 回归**  
用于多分类问题。  
输出经过 softmax 得到每一类概率：

\[
softmax(o_i)=\frac{e^{o_i}}{\sum_j e^{o_j}}
\]

损失函数常用交叉熵。

**MLP 多层感知机**  
在线性层之间加入激活函数，例如 ReLU，否则多层线性层叠加仍然等价于一个线性层。

高频题：

> 为什么 MLP 需要激活函数？

答：如果没有非线性激活函数，多层线性变换仍然可以合并成一个线性变换，模型表达能力不会增强。

---

### 3. 权重衰退、Dropout

这个非常爱考。

**权重衰退**本质是 L2 正则化：

\[
L + \lambda ||w||^2
\]

作用：限制权重过大，缓解过拟合。

**Dropout**  
训练时随机丢弃一部分神经元，测试时使用完整网络。  
作用：减少神经元之间的依赖，缓解过拟合。

高频填空：

> Dropout 通常只在训练阶段使用，测试阶段关闭。

---

### 4. 卷积神经网络 CNN、LeNet、AlexNet、VGG、GoogLeNet、ResNet

这部分大概率会考模型结构区别。

你不用死背全部细节，但要知道：

| 模型 | 核心特点 |
|---|---|
| LeNet | 早期 CNN，用于手写数字识别 |
| AlexNet | 更深，使用 ReLU、Dropout、数据增强，推动深度学习发展 |
| VGG | 使用多个小卷积核，例如 3×3，结构规整 |
| GoogLeNet | Inception 模块，多尺度卷积 |
| ResNet | 残差连接，解决深层网络退化问题 |

ResNet 必须会：

\[
y = F(x) + x
\]

高频简答：

> ResNet 为什么能训练很深的网络？

答：通过残差连接让信息和梯度更容易传播，缓解梯度消失和网络退化问题。

---

### 5. RNN、GRU、LSTM、双向 RNN

这部分也很可能考简答或选择。

你要会区分：

| 模型 | 特点 |
|---|---|
| RNN | 处理序列数据，有隐藏状态 |
| GRU | 有更新门、重置门，结构比 LSTM 简单 |
| LSTM | 有输入门、遗忘门、输出门，缓解长期依赖问题 |
| 双向 RNN | 同时利用过去和未来上下文 |

高频题：

> 为什么普通 RNN 难以处理长序列？

答：因为反向传播时容易出现梯度消失或梯度爆炸，导致长期依赖难以学习。

---

### 6. Seq2Seq + Attention

你老师范围里专门写了 `Seq2seq+attention`，这个非常值得押。

Seq2Seq 用于机器翻译：

编码器：把输入序列编码成隐藏状态。  
解码器：根据编码结果逐步生成输出序列。

普通 Seq2Seq 的问题：所有信息压缩到一个固定长度向量，长句效果差。

Attention 的作用：解码时根据当前状态，对输入不同位置分配不同权重。

高频简答：

> Attention 机制解决了什么问题？

答：解决了 Seq2Seq 中固定长度上下文向量的信息瓶颈，使解码器能够动态关注输入序列中不同位置的信息。

---

### 7. Transformer、BERT

这个几乎必考，特别是选择、填空、简答。

Transformer 核心：

- 不使用 RNN
- 依赖自注意力机制
- 可以并行计算
- 使用位置编码表示词序

自注意力公式最好背：

\[
Attention(Q,K,V)=softmax(\frac{QK^T}{\sqrt{d_k}})V
\]

BERT 核心：

- 基于 Transformer Encoder
- 双向编码
- 预训练 + 微调
- 常用于自然语言推理、文本分类、问答等任务

高频题：

> BERT 为什么是双向的？

答：BERT 使用 Transformer Encoder，通过自注意力同时建模左右上下文，因此能够获得双向语义表示。

---

### 8. 数值稳定性、初始化、激活函数

这部分容易出填空和简答。

重点：

**梯度消失**：梯度越来越小，前面层学不到。  
**梯度爆炸**：梯度越来越大，训练不稳定。

解决方法：

- 合理初始化，例如 Xavier、He 初始化
- 使用 ReLU
- Batch Normalization
- 残差连接
- 梯度裁剪，尤其是 RNN

激活函数：

| 函数 | 特点 |
|---|---|
| Sigmoid | 输出 0 到 1，容易梯度消失 |
| Tanh | 输出 -1 到 1，也可能梯度消失 |
| ReLU | 简单高效，缓解梯度消失 |
| Softmax | 多分类输出概率 |

## 1. PyTorch 训练基本流程

这个必须会。

```python
for epoch in range(num_epochs):
    model.train()
    for X, y in train_iter:
        y_hat = model(X)
        loss = loss_fn(y_hat, y)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
```

核心顺序一定要记住：

```python
预测 -> 计算损失 -> 梯度清零 -> 反向传播 -> 参数更新
```

## 2. 定义 MLP

```python
import torch
from torch import nn

model = nn.Sequential(
    nn.Flatten(),
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Dropout(0.5),
    nn.Linear(256, 10)
)
```

考点：

- `Flatten()`：把图片拉平成向量
- `Linear(784, 256)`：全连接层
- `ReLU()`：非线性激活
- `Dropout(0.5)`：随机丢弃 50%
- 最后一层输出类别数，例如 10 类就是 10

## 3. 定义 CNN

```python
model = nn.Sequential(
    nn.Conv2d(1, 6, kernel_size=5),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2, stride=2),
    nn.Conv2d(6, 16, kernel_size=5),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2, stride=2),
    nn.Flatten(),
    nn.Linear(16 * 4 * 4, 120),
    nn.ReLU(),
    nn.Linear(120, 84),
    nn.ReLU(),
    nn.Linear(84, 10)
)
```

这里像 LeNet，可能考你补空。

重点看懂：

```python
nn.Conv2d(输入通道数, 输出通道数, kernel_size)
```

例如 RGB 图片输入通道是 3，灰度图输入通道是 1。

## 4. 损失函数选择

| 任务 | 最常用损失 |
|---|---|
| 回归 | MSELoss |
| 多分类 | CrossEntropyLoss |
| 二分类 | BCELoss 或 BCEWithLogitsLoss |
| 语义分割 | CrossEntropyLoss |
| 目标检测 | 分类损失 + 边界框回归损失 |

注意：`CrossEntropyLoss` 通常直接接收原始 logits，不需要你手动先 softmax。

# 五、简答题押题

## 1. 简述过拟合和欠拟合的区别。

欠拟合是模型过于简单，训练误差和测试误差都较高。  
过拟合是模型过度记住训练集，训练误差低但测试误差高。  
欠拟合可以通过增加模型复杂度、增加特征、训练更久解决。  
过拟合可以通过增加数据、正则化、Dropout、数据增强、早停解决。

---

## 2. 为什么 CNN 适合图像任务？

CNN 使用卷积核提取局部特征，参数共享减少参数量，平移不变性使其适合处理图像。池化层可以降低空间尺寸并增强鲁棒性。因此 CNN 在图片分类、目标检测、语义分割中表现良好。

---

## 3. RNN、GRU、LSTM 的区别。

RNN 用隐藏状态处理序列数据，但容易出现梯度消失，难以学习长期依赖。  
GRU 使用更新门和重置门控制信息流，结构较简单。  
LSTM 使用输入门、遗忘门、输出门和记忆单元，更适合处理长期依赖。

---

## 4. Attention 的作用是什么？

Attention 让模型在生成当前输出时，根据相关性动态关注输入序列的不同位置。它解决了传统 Seq2Seq 把全部信息压缩到固定长度向量中的瓶颈问题，尤其适合机器翻译等序列任务。

---

## 5. Transformer 相比 RNN 有什么优势？

Transformer 不依赖循环结构，而是使用自注意力机制建模序列中任意位置之间的关系。它可以并行计算，训练效率更高，并且更容易捕捉长距离依赖。

---

## 6. 什么是微调？

微调是指先使用大规模数据训练一个预训练模型，然后在具体任务的小数据集上继续训练部分或全部参数。这样可以利用预训练模型学到的通用特征，提高下游任务效果。

# 六、考前最值得背的公式

你现在不用背太多，背这些就够应付大部分题。

## Softmax

\[
softmax(o_i)=\frac{e^{o_i}}{\sum_j e^{o_j}}
\]

## 交叉熵

\[
L=-\sum_i y_i \log \hat y_i
\]

单标签分类时常写成：

\[
L=-\log \hat y_y
\]

## 权重衰退

\[
L' = L + \lambda ||w||^2
\]

## Attention

\[
Attention(Q,K,V)=softmax(\frac{QK^T}{\sqrt{d_k}})V
\]

## 卷积输出尺寸

\[
\frac{n-k+2p}{s}+1
\]

其中：

- \(n\)：输入尺寸
- \(k\)：卷积核大小
- \(p\)：padding
- \(s\)：stride

这个公式很可能考填空或计算。

# 九、最短救命版

现在真的看不进去了，就背这几句话：

**过拟合**：训练好、测试差；用 Dropout、权重衰退、数据增强、早停。  
**欠拟合**：训练和测试都差；增大模型、增加特征、训练更久。  
**CNN**：图像；卷积提特征，池化降维。  
**RNN/LSTM/GRU**：序列；LSTM/GRU 解决长期依赖。  
**Attention**：让模型关注输入中重要位置。  
**Transformer**：自注意力，可并行，适合长距离依赖。  
**BERT**：Transformer Encoder，双向预训练，微调用于下游 NLP。  
**ResNet**：残差连接，解决深层网络难训练。  
**YOLO/SSD/R-CNN**：目标检测。  
**FCN**：语义分割。  
**训练代码顺序**：forward → loss → zero_grad → backward → step。

这套背熟，至少能把选择、填空、简答和综合题的大部分分拿住。

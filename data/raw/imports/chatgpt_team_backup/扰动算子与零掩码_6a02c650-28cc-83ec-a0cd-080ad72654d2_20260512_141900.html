1. 扰动算子在决定 ASS 符号方面起关键作用——而零掩码（zero-masking）会产生伪影。
一项预注册的 8 轮有效性测试（表 XI）在 ResNet（CLBBB/QRS 与 1AVB/PR）以及一个 SE-ResNet 哨兵模型上评估了三种扰动算子。

在零掩码条件下，由于 ST 段被遮挡导致 AUROC 出现人为的大幅下降（Δ = 0.706），CLBBB 的 ASS 为 −0.010（95% CI [−0.011, −0.008]）。
这是一种“硬边界伪影”：零掩码会产生突兀的信号不连续，而卷积滤波器会对此产生强烈响应，这种响应与被遮挡区域的生理学内容无关。

线性插值消除了该边界效应，并恢复了可解释的行为：ST 的 ΔAUROC 降至 0.166，而 QRS 目标的 ΔAUROC 保持稳定在 0.322，从而使 CLBBB 的 ASS 变为 +0.083（95% CI [0.073, 0.094]）。

Beat-conditioned inpainting 则过于保守，几乎无法区分（所有 Δ≈0）。

因此，该有效性测试表明：
(i) 线性插值是匹配对照扰动研究中更优的算子；
(ii) 先前关于“ST 段是通用干扰因素”的结论主要源于零掩码伪影；
(iii) 扰动算子本身具有诊断意义——那些依赖特定扰动算子的结论是脆弱的，不应被视为通路特异性证据。

预注册有效性测试：
为检验“匹配对照结论”是否实际上是由扰动算子引起的伪影，而非真实的通路特异性信号，我们进行了一个包含 8 次运行的确认性实验，并预先注册了假设、评价指标与通过/失败标准（完整预注册内容见补充材料）。

主要模型为 ResNet；哨兵模型为 SE-ResNet。
疾病-通路配对包括：CLBBB/QRS（预期具有正向特异性）以及 1AVB/PR（预期为非特异性）。

使用三种扰动算子：零掩码（zero-masking）、线性插值（保持连续性）以及 beat-conditioned inpainting（基于相邻心搏幅度对齐的替换方法）。

额外分析维度包括：剂量-反应关系（40/80/160/240 ms）以及导联局部特异性（胸前导联 V1/V2/V6 vs 肢体导联）。

所有实验均使用相同的匹配正负样本子集，并采用患者级 bootstrap 置信区间（1,000 次迭代）。

预注册的主要终点要求：
- 对于 CLBBB：在 ≥3 种算子中至少 2 种满足 ASS > 0 且置信区间下界 > 0
- 对于 1AVB：在 ≥3 种算子中至少 2 种满足 ASS ≤ 0 且置信区间上界 ≤ 0

次要终点包括：剂量-反应的单调性，以及导联局部特异性。

## 🤖 Assistant (2026/6/1 11:54:19)

`Teammate mode` 不是“协作权限”或“模型聪明程度”的设置，而是 **Claude Code 的 Agent Teams 里，多个 teammate/队友会话在终端里怎么显示**。Agent Teams 是一种实验功能：一个 Claude Code 会话当 team lead，其他独立 Claude Code 实例当 teammates，各自有独立上下文窗口，可以通过任务列表和消息协作。citeturn300223view0

几个可选值一般是：

| 值 | 含义 | 适合场景 |
|---|---|---|
| `auto` | 自动选择显示方式。官方说明是：能用 split panes 时用分屏，否则用 `in-process`。CLI 里它是默认值。citeturn470271view1turn470271view2 | 不想折腾，推荐默认用这个 |
| `in-process` | 所有 teammates 都在你当前主终端里运行。用 `Shift+Down` 在 lead 和不同 teammate 之间切换，并直接给某个 teammate 发消息；不需要额外安装，任何终端基本都能用。citeturn300223view0 | 最稳、最省事，VS Code 终端/普通终端优先用 |
| `tmux` | 使用分屏模式：每个 teammate 有自己的 pane，可以同时看多个 teammate 的输出，也可以点进某个 pane 直接交互。需要 `tmux`，或 iTerm2 配合相关 CLI/Python API。citeturn300223view0 | 你想实时观察多个 agent 并行工作，且熟悉 tmux/iTerm2 |

配置示例：

```json
{
  "teammateMode": "in-process"
}
```

也可以只对本次启动临时覆盖：

```bash
claude --teammate-mode in-process
```

官方也说明 `--teammate-mode` 会覆盖 `settings.json` 里的 `teammateMode`，但只影响当前这次 session。citeturn470271view2

我的建议：**普通用户选 `auto` 或 `in-process` 就行**。只有你明确想用分屏同时盯多个 Claude Code 队友，才选 `tmux`。另外 Agent Teams 会明显增加 token 使用量，因为每个 teammate 都是独立上下文窗口，队伍越大成本越高。citeturn470271view0

# 1. 现成可用的 MCP / Skill 方向（SSH / Remote）

## A. MCP SSH / Remote Shell 类（最直接）

目前社区里比较常见的是这一类 MCP Server：

### ① SSH MCP Server（最接近你需求）
功能：
- 建立 SSH 连接
- 执行远程命令
- 读写远程文件
- 作为 tool 暴露给 Claude Code

典型能力形态：
- ssh_exec(command)
- ssh_read_file(path)
- ssh_write_file(path)
- ssh_list_dir(path)

👉 适合：把远程服务器当“工具执行环境”

---

### ② Remote FS MCP（文件系统映射）
类似：
- 把远程目录 mount 成 tool
- Claude Code 直接像操作本地一样操作远程文件

底层实现：
- SSHFS / SFTP / rsync

👉 适合：开发同步 + 代码编辑

---

### ③ Terminal / Shell MCP（本地代理 + SSH）
一些 MCP 实现会提供：

- run_shell()
- run_remote_shell(host, command)

本质：
- 本地 MCP server 做 proxy
- 再 SSH 到远程执行

---

## B. Claude Code “Skills”方式（如果你指的是 skill system）

Skill 本身通常：
- 不负责网络连接
- 但可以封装：
- ssh tool usage pattern
- remote execution workflow

例如：
- deploy_skill
- remote_debug_skill

👉 本质仍然是 MCP tool wrapper

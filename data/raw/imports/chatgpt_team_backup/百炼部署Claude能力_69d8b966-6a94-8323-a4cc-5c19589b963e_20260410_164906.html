## 一、为什么会有这个误解？
你看到的“Claude Code 百炼部署方法”，本质上通常指：

- 在百炼中配置：
- 模型（如 Claude 系列或兼容模型）
- API Key
- 调用参数（temperature / max tokens 等）
- 然后通过：
- HTTP API
- SDK（Python / Node）
- 或 Agent 编排

➡️ 这其实是“调用 Claude 能力”，而不是“部署 Claude Code”。

---

## 二、Claude Code 到底是什么？
“Claude Code”更接近：

- 一个 开发者工具链 / coding agent
- 类似：
- entity["software","GitHub Copilot","AI coding assistant"]
- entity["software","Cursor","AI code editor"]
- 或 CLI Agent（如自动写代码、执行、修改）

它通常包含：

1. LLM（Claude 模型）
2. 工具调用（shell / git / file system）
3. 任务规划（agent loop）
4. 本地或远程执行环境

👉 百炼只覆盖第 1 点（模型），不覆盖 2–4。

## 四、如果你真的想“部署 Claude Code”，该怎么做？
现实可行路径是三层架构：

### ① Agent 层（你要自己做）
可以用：

- entity["software","LangChain","LLM framework"]
- entity["software","AutoGen","multi-agent framework"]
- 或你之前提到的 MCP / skill system

- task planning
- tool use（SSH / git / file）

---

### ② 模型层（百炼提供）
- Claude-like 模型（或其他 LLM）

---

### ③ 执行环境（关键）
你需要：

- 本地 shell / Docker
- 或远程服务器（SSH）
- 文件系统访问

👉 这部分百炼完全不管

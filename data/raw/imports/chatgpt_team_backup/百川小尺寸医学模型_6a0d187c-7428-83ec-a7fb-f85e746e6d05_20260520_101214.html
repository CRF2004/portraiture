有，但要看你说的“小尺寸”到什么程度。

目前公开能确认的百川医学/医疗相关开源模型主要有这些：

| 模型 | 参数量 | 是否医学方向 | 是否算小尺寸 |
|---|---:|---|---|
| Baichuan-M1-14B | 14B | 医疗场景优化，从零训练，提供 Base / Instruct | 相对小，但不是 7B 级 |
| Baichuan-M2-32B | 32B/33B | 医疗增强推理模型 | 中等偏大，但有量化版，可单卡部署说法 |
| BaichuanMed-OCR-7B | 约 7B/8B | 医学 OCR / 图文理解方向 | 小尺寸，但不是通用医学问答模型 |
| Baichuan-M3-235B | 235B | 新一代医疗增强模型 | 不小，属于大模型 |

所以结论是：有“小一点”的开源医学模型，最典型是 Baichuan-M1-14B；如果你要 7B 级通用医学问答模型，百川目前公开主线里没有明确的 Baichuan-Med-7B 通用问答模型。 7B 级更接近的是 BaichuanMed-OCR-7B，但它偏医学 OCR/图文任务，不是纯文本医疗问答。citeturn914369search0turn137461search15

如果你是想本地部署医疗问答，优先看：

1. Baichuan-M1-14B-Instruct：医疗能力更对口，体量还能接受。
2. Baichuan-M2-32B 的量化版：能力更强，但显存压力更大。Hugging Face 上也能看到 M2/M3 的 GGUF/GPTQ/FP8 等版本。citeturn137461search2turn137461search15
3. BaichuanMed-OCR-7B：只有在你要处理病历、报告、影像文字识别/医学图文理解时才优先考虑。citeturn137461search15

一句话：百川有开源医学模型，但“小尺寸通用医疗问答”最接近的是 14B 的 Baichuan-M1，不是 7B。

MedGemma 最小是 4B。

公开的 MedGemma 主要尺寸是：

| 模型 | 参数量 | 类型 |
|---|---:|---|
| MedGemma 4B / MedGemma 1.5 4B | 4B | 多模态：医学图像 + 文本输入，文本输出 |
| MedGemma 27B | 27B | 文本-only 版本；后续也有 27B 多模态版本 |

Google 官方资料写明 MedGemma 发布为 4B 和 27B 两个参数规模；MedGemma 1.5 也保留了 4B 版本，并增强了医疗影像相关能力。citeturn876871search2turn876871search4turn876871search14

所以如果你在找“很小的医学模型”，MedGemma 目前没有 1B/2B/3B 医学版，最小就是 4B。实际部署上，4B 量化后通常比 7B/14B 轻很多，适合单卡或较强消费级显卡尝试；但医疗推理能力通常不如 27B。

| 问法 | 答案 |
|---|---|

| 能商用吗？ | 要看 Google 的 HAI-DEF / Gemma 相关条款 |

依据是：

1. JoyMed-8B 是多模态模型，官方介绍它做医学图像理解、文档理解、医学报告生成等任务，不是纯文本 LLM。官方 benchmark 里也把它和 Qwen3-VL 8B / Qwen3-VL 32B、MedGemma、HuatuoGPT-V、Lingshu、Citrus-V 等视觉语言模型放在一起比较。citeturn172217view0

2. Hugging Face 公开索引里把 jdh-algo/JoyMed-8B-v1.0 标成 Image-Text-to-Text，约 9B，这也说明它是视觉语言模型。citeturn932632search4

3. 官方运行方式要求 vllm serve ... --mm-encoder-tp-mode data ... --trust-remote-code，并要求升级到 transformers==5.2.*，这更像是新一代多模态架构/自定义 remote code，而不是普通 Llama/Qwen 文本模型。citeturn172217view0

我的判断：JoyMed-8B 大概率是基于 Qwen3-VL-8B 一类视觉语言架构做的医疗后训练/强化训练，但目前公开 README 没有把“底座模型”明说。

| 项目 | 判断 |
|---|---|
| 直接按 qwen3_vl 接 SWIFT | 值得尝试 |
| 直接按普通 Qwen3-8B 文本模型接 | 不建议 |
| 确认是否能无改动支持 | 必须看本地 config.json |
| 最关键字段 | model_type、architectures、auto_map |

cat config.json | grep -E "model_type|architectures|auto_map|vision|qwen"

"model_type": "qwen3_vl"

"architectures": ["Qwen3VLForConditionalGeneration"]


那基本就能按 Qwen3-VL 系去尝试 SWIFT 适配。

对，这个 unsloth/medgemma-1.5-4b-it 原则上可以用 SWIFT 微调，但要注意：它不是 SWIFT 官方表里直接列名的 google/medgemma-4b-it，而是 Unsloth 转存/优化版本。

判断依据：

SWIFT 官方支持 MedGemma 4B IT/PT，对应 model_type 是 gemma3_vision，依赖要求是 transformers>=4.49。citeturn310838view1
而 MedGemma 1.5 4B 官方说明里明确说它是 Gemma 3 variants，用于医疗文本和图像理解，属于同一类 Gemma 3 Vision / MedGemma 4B 多模态架构。citeturn390092view2

所以你可以先这样试：

swift sft \
  --model unsloth/medgemma-1.5-4b-it \
  --model_type gemma3_vision \
  --train_type lora \
  --dataset your_dataset.jsonl \
  --torch_dtype bfloat16 \
  --num_train_epochs 1 \
  --per_device_train_batch_size 1 \
  --gradient_accumulation_steps 8 \
  --learning_rate 1e-4 \
  --save_steps 500 \
  --output_dir output/medgemma15_lora


如果你用的是 ModelScope 地址，也可以写成：

swift sft \
  --model unsloth/medgemma-1.5-4b-it \
  --model_type gemma3_vision \
  --train_type lora \
  --dataset your_dataset.jsonl


关键是这几个点：

| 项目 | 建议 |
|---|---|
| model_type | 用 gemma3_vision |
| 微调方式 | 优先 LoRA / QLoRA |
| 数据 | 文本 SFT 可以；图文 SFT 要按 SWIFT 多模态格式 |
| 依赖 | 至少 transformers>=4.49，实际建议用较新的 SWIFT 环境 |
| 风险 | Unsloth 版本如果改了文件结构，可能需要改用 google/medgemma-4b-it 或 google/medgemma-1.5-4b-it 原版 |

我建议你先跑一个最小 smoke test，不要一上来正式训练：

swift infer \
  --model unsloth/medgemma-1.5-4b-it \
  --model_type gemma3_vision


如果推理能加载，再上 swift sft。如果这里报 config、processor、vision_tower、chat_template 相关错误，直接换 Google 原版 MedGemma 1.5 4B 或 SWIFT 官方表里的 google/medgemma-4b-it 更稳。

modelscope的话怎么下载模型到指定文件夹？
🤖Assistant2026/5/20 11:02:27
可以，用 ModelScope CLI 的 --local_dir 最直接。

以你这个模型为例：

pip install -U modelscope


modelscope download \
  --model unsloth/medgemma-1.5-4b-it \
  --local_dir /data/models/medgemma-1.5-4b-it


--local_dir 会把模型文件直接放到你指定的目录；ModelScope 官方文档也说明，local_dir 优先级高于 cache_dir。citeturn438107search0turn438107search3

如果你只是想改默认缓存目录，也可以这样：

export MODELSCOPE_CACHE=/data/modelscope_cache

modelscope download \
  --model unsloth/medgemma-1.5-4b-it


或者用 Python 下载：

from modelscope import snapshot_download

model_dir = snapshot_download(
    "unsloth/medgemma-1.5-4b-it",
    local_dir="/data/models/medgemma-1.5-4b-it"
)

print(model_dir)


我更建议你用第一种 --local_dir，后面 SWIFT 微调时直接写本地路径：

swift sft \
  --model /data/models/medgemma-1.5-4b-it \
  --model_type gemma3_vision \
  --train_type lora \
  --dataset your_dataset.jsonl


如果下载 gated/需要登录的模型，先执行：

modelscope login


或：

modelscope login --token YOUR_TOKEN
